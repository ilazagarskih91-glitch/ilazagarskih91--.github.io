САЙТ-ПАМЯТКА: «ИИ Ищи — ищи ответы, проверяй факты.»

ФАЙЛЫ
- index.html — адаптивный сайт в светлом стиле, анимация диалога с ИИ, конструктор запросов, курсы и форма записи на консультацию.
- pamyatka.html — обновлённая памятка с формулой хорошего запроса, проверкой ответов и макетом для печати на листе A4.
- qr-placeholder.svg — заглушка вместо рабочего QR-кода.
- generate_qr.py — создаёт рабочий QR-код после публикации сайта.
- open_site.bat — быстрый запуск сайта в браузере на Windows.

КАК ОТКРЫТЬ
Распакуй архив и открой index.html в браузере. Чтобы распечатать краткую памятку, открой pamyatka.html и нажми «Печать / сохранить в PDF».

КАК СДЕЛАТЬ РАБОЧИЙ QR-КОД
Пока сайт находится только на компьютере, у него нет общего публичного адреса. Сначала опубликуй сайт на статическом хостинге и получи URL вида https://...

После публикации:
1. Установи библиотеку: python -m pip install "qrcode[pil]"
2. Запусти в этой папке: python generate_qr.py https://ВАШ-АДРЕС-САЙТА/
3. Скрипт создаст qr.png и заменит QR-заглушки в index.html и pamyatka.html.
4. Загрузить обновлённые файлы на хостинг и проверить QR телефоном.

Не используй qr-placeholder.svg как настоящий QR — это только заглушка.
