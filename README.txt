САЙТ-ПАМЯТКА: «ИИ Ищи — ищи ответы, проверяй факты.»

ФАЙЛЫ
- index.html — адаптивный сайт в тёмном стиле, анимация диалога с ИИ, конструктор запросов, курсы и форма записи на консультацию.
- pamyatka.html — обновлённая памятка с формулой хорошего запроса, проверкой ответов и макетом для печати на листе A4.
- qr.png — рабочий QR-код для опубликованного сайта.
- generate_qr.py — создаёт рабочий QR-код после публикации сайта.
- open_site.bat — быстрый запуск сайта в браузере на Windows.

КАК ОТКРЫТЬ
Распакуй архив и открой index.html в браузере. Чтобы распечатать краткую памятку, открой pamyatka.html и нажми «Печать / сохранить в PDF».

КАК ОБНОВИТЬ QR-КОД ПРИ СМЕНЕ АДРЕСА
Если адрес сайта изменится, установи Python и библиотеку qrcode[pil], затем запусти в этой папке:
python -m pip install "qrcode[pil]"
python generate_qr.py https://НОВЫЙ-АДРЕС-САЙТА/
После этого отправь обновлённые файлы в GitHub. Проверь QR-код камерой телефона.
